Minor Project 2: Task Manager<br/>
Objective<br/>
  Develop a Task Manager Web Application using HTML, CSS, and JavaScript to manage daily tasks efficiently.<br/>
Mandatory File Structure<br/>
  You must create and maintain the following three separate files:<br/>
  ● index.html<br/>
  ● style.css<br/>
  ● script.js<br/>
Note: Inline CSS and JavaScript will not be accepted.<br/>
Project Features<br/>
  ● Add new tasks<br/>
  ● Display list of tasks<br/>
  ● Mark tasks as completed<br/>
  ● Delete tasks<br/>
Functional Expectations<br/>
  ● Clean and responsive user interface<br/>
  ● Proper DOM manipulation using JavaScript<br/>
  ● Tasks should update dynamically without page reload<br/>
