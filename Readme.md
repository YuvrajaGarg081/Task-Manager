Minor Project 2: Task Manager
Objective
Develop a Task Manager Web Application using HTML, CSS, and JavaScript to manage
daily tasks efficiently.
Mandatory File Structure
You must create and maintain the following three separate files:
● index.html
● style.css
● script.js
Note: Inline CSS and JavaScript will not be accepted.
Project Features
● Add new tasks
● Display list of tasks
● Mark tasks as completed
● Delete tasks
Functional Expectations
● Clean and responsive user interface
● Proper DOM manipulation using JavaScript
● Tasks should update dynamically without page reload
